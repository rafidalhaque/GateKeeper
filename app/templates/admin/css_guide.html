📄 Page Setup (@page)

Common Page Sizes

Size Dimensions Use Case CSS Code

A5 148 × 210mm Half-page tickets size: A5;

Custom Any size Special requirements size: 100mm 150mm; 
@page {
    size: A4 portrait;  /* or landscape */
    margin: 20mm;       /* All sides */
    /* Or individually: */
    margin-top: 20mm;
    margin-right: 15mm;
    margin-bottom: 20mm;
    margin-left: 15mm;
}
Units: Use mm (millimeters), cm (centimeters), in (inches), or px (pixels)

📐 Layout & Flexbox

/* Center content */
.container {
    display: flex;
    justify-content: center;  /* horizontal */
    align-items: center;       /* vertical */
    flex-direction: column;    /* stack items */
}
/* Two-column layout */
.row {
    display: flex;
    justify-content: space-between;
}
/* Full height */
.badge {
    height: 2in;
    box-sizing: border-box;
}

✍️ Typography

body { font-family: Arial, sans-serif; }
h1 { font-size: 32px; font-weight: bold; }
h2 { font-size: 24px; font-weight: 600; }
p { font-size: 16px; line-height: 1.5; }
.small { font-size: 12px; }
PDF Safety: Stick to common fonts: Arial, Helvetica, Times New Roman, Courier, Georgia

Text Alignment & Transform

text-align: center;      /* left, center, right, justify */
text-transform: uppercase; /* lowercase, capitalize */
text-decoration: underline; /* none, line-through */

📏 Spacing (Padding & Margin)

/* Padding (inside spacing) */
padding: 20px;              /* All sides */
padding: 10px 20px;         /* Top/Bottom, Left/Right */
padding: 10px 15px 20px 15px; /* Top, Right, Bottom, Left */
/* Margin (outside spacing) */
margin: 20px;               /* All sides */
margin: 0 auto;             /* Center horizontally */
margin-top: 30px;
Tip: Use consistent spacing (10px, 20px, 30px) for professional look

📧 Email Template Best Practices

Email clients are limited!
  • Use tables for layout (not flexbox)
  • Inline CSS only (no <style> tags)
  • Avoid advanced CSS (transforms, animations)
  • Test in multiple clients (Gmail, Outlook, etc.)

Safe Email Template Structure

<table width="600" cellpadding="0" cellspacing="0">
  <tr>
    <td style="padding: 20px; background: #f5f5f5;">
      <h1 style="color: #333; font-family: Arial;">Hello!</h1>
      <p style="color: #666; line-height: 1.5;">Content here</p>
    </td>
  </tr>
</table>

✅ Do's

  • Use inline styles
  • Set explicit widths (e.g., width="600")
  • Use hex colors (#ffffff)
  • Keep max width ~600px for mobile
  • Use absolute image URLs

❌ Don'ts

  • No flexbox or grid
  • No position: absolute/fixed
  • No background images (limited support)
  • No web fonts (stick to Arial, Georgia, etc.)
  • No JavaScript
